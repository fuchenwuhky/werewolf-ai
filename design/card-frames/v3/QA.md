# 月蚀圣龛 V3 · 设计包验图记录

日期：2026-09-23。范围仅为本设计目录，不是正在施工的游戏业务代码验收。

## 结论

推荐大卡采用 **金属 PNG＋SVG 徽记＋HTML 铭牌**，小卡采用 **R2 纯 SVG 精雕薄框**。四种已知角色主题、统一中性牌背已使用项目真实角色图验证，未覆盖原立绘、原卡框或施工方业务文件。

完整纯 SVG 是无位图备选与故障回退，不宣称与生成金属纹理具有相同的雕刻细节。它的价值是可编辑、轻量、可缩放与不依赖 PNG。

## 初版故障回退实测（历史）

在隔离的预览页面里，把单个图片地址临时改为不存在的测试地址，等待真实 error 事件。没有改动落盘源码或用户游戏数据。

1. 金属 PNG 失败：完整 SVG 的计算样式为 `display:block`。
2. 进一步让完整 SVG 失败：损坏图为 `display:none`，CSS 细边框为 `display:block`。
3. 52px 简版 SVG 失败：损坏图隐藏，CSS 细边框显示。

测试产生的 404 为明确注入的故障，恢复页面后素材加载正常。立绘失败状态另外由组件契约检查覆盖；未把静态桩断言冒充真实设备磁盘故障测试。
