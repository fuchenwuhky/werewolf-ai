## 2. 视觉体系

基调：煤黑、雾灰、象牙白、克制暗金，使用原有狼冠与 V3/R2 卡框。哥特感主要来自月夜城堡背景、尖拱角色画面、宋体标题、细金属雕刻分隔线；表单保持清晰，不给所有容器添加厚重花边。

颜色来自 `tokens.css`（仅提案，不直接注入全局）。3 个集合共 43 个变量：12 原始色、15 语义色、16 尺寸变量。保留色彩语义，不用红色代表普通选中；错误使用浅红文字与明确描述，成功、出局和选中都有文字标识。默认输入边界使用次级文字色的 60% 混合，约 3.85:1；普通装饰分隔线可较暗，不能拿来充当输入框唯一边界。

标题 Noto Serif SC；正文 Noto Sans SC；英文铭文 Cinzel Decorative。正文 16/26，次级 14/22，附注 12/18；手机主要标题 24/34，桌面 32/44，英雄区 48/64。中文正文不使用英文装饰字体。离线客户端必须保证字体可用；若采用裁切字体，冷僻字使用明确的中文 fallback，不能显示方框。

页面主间距 24/32；手机边距 16；卡片内边距 24；表单内边距 12–16。主按钮 52px，其他交互热区至少 48px。只有纯信息徽标允许 30px。可点击筛选、加减头像缩放都有独立 48px 触区。焦点环使用浅月蓝，不能仅靠 hover。

## 3. 响应式与滚动

桌面基准 1440×900，常驻侧栏 224，内容区 1216，内容左右留白 32。建议从 1200px 以下折叠侧栏，使用 48px 以上菜单按钮及抽屉；960px 适配稿展示内容重新排布，不是整体缩放。

手机基准 390×844；状态栏、应用栏和底部导航独立，正文区域纵向滚动。所有产品页接入 `safe-area-inset-*` 和 `dvh`；不能把画板的 844px 写死成页面高度。320px/大字模式转单列或重新分配栅格，正文和按钮不整体缩小。角色与人物卡列表按可用宽度调整列数，不强塞固定两列导致横向滚动。

局内底部为“对局 / 行动 / 笔记”；局外为“大厅 / 对局 / 图鉴 / 我的”。图鉴内可切换角色与 AI 来客，设置与 AI 配置由“我的”和大厅的模型入口到达；桌面保留直接导航。

软键盘弹出时使用 `visualViewport`/实际可用高度保障编辑区与确认按钮可见；收起不必要的全局底栏，保留草稿。Q01 的键盘只是系统区域示意，禁止实现自制英文键盘。弹窗有最大高度、内部滚动和安全区；不要让固定底栏覆盖最后一个字段或保存按钮。

## 4. 档案与自定义头像（最高优先级）

01 选择本机档案进入；02 编辑昵称、简介及头像；03 本机裁切；04 玩家中心；05 管理与归档；31 移入回收站确认；42 回收站恢复。不能将“登录”解释为需要联网账号。

昵称 trim 后 1–20 个 Unicode 码点，简介最多 100 个码点，复用 `web/shared/profile-state.js` 与服务端校验。不要用 JS 字符串 `.length` 重新制造中英文/emoji 长度不一致。错误保留输入并定位到字段。

头像复用 `web/shared/avatar-image.js` 和 `src/profiles/avatar.js`：来源 PNG/JPEG/WebP，不超过 10 MiB，边长不超过 8192；本机解码裁切成 512×512 PNG，上传不超过 2 MiB。尊重现有 CSP，裁切预览走 canvas，不擅自放宽 CSP 或使用会被拦截的 blob 图片标签。缩放、平移、键盘可操作，确认前显示 96/64/40 三档预览；失败保留原头像；移除自定义头像回退合法内置徽记。使用服务端返回的 `avatarUrl` 与内容哈希，不自己拼接上传前哈希。

档案创建/编辑保存必须处理 revision 409、IO 故障和离线，不以 toast 代替真实成功。当前档案与对局 owner 分开：开局固定 profileId，切换档案不转移 owner。

删除语义必须对齐当前代码：只能将符合条件的已归档档案移入可恢复回收站，**不是永久销毁**。保留最后一个可用档案保护、进行中对局保护及故障恢复。回收站区分空、读取失败、删除未完成、恢复中、恢复失败与已恢复；恢复成功后刷新索引并成为可用档案，不要求用户再手工取消归档。设计不增加永久清空功能。

27/41 的跨档案只读分支是显式的产品优化要求：当前档案与本局 owner 同时显示；默认不展示原 owner 私人笔记和私密角色信息；切回 owner 后才允许继续操作。接入时须核对现有授权视图，不能只在 CSS 隐藏已经泄漏到公共 DOM 的内容。若无法安全支持跨档案只读，先只开放“切回原档案 / 取消”，不要做假隔离。

## 5. 大厅、开局与 AI 配置

大厅优先级：开始新局、恢复未完对局、试玩/真实 AI 区别、人物与角色入口。恢复卡依赖服务端状态，不仅依靠浏览器旧句柄；服务重启后可从磁盘恢复并换发令牌。404、已结束与临时网络故障不能混成“没有存档”。

07–09 三步开局：板子/规则 → 参与方式/座位/AI → 总确认。前两步只编辑草稿，不创建对局、不产生模型请求；提交防重复。确认页明确档案、人数、板子、座位、参与模式、模型和费用。无 Key 可以明确切到免费 Mock；Mock 不宣称为真实模型表现。

39 是自定义规则编辑模板。角色数和规则项读取当前配置，不照抄演示的 12 人组合。非法数量、互斥角色和特殊规则就地报错，不用静默截断或替用户改人数。

10 的 base_url、主模型和 API Key 为第一层；快速模型、额外 Key、温度、token 上限、思考强度、上下文和并发探测为第二层。设计展示高级区展开态，真实默认可收起。测试连接须显示目标与可能的模型费用，提交中锁住重复触发，显示成功/失败/超时，不泄漏密钥。

保留地址与密钥双通道合取绑定、额外 Key 不随迁、重新确认信任等已修复规则。37 清空附加 Key 与档案删除完全不同，确认内容不得混用。密钥属于设备级配置，不随档案切换或导出。

11 为席位与人格编辑，目前默认继承设备模型。不要根据页名伪造尚未实现的每席多服务商/多 Key 能力；如需扩展，另列数据模型与成本方案。人物风格不等于游戏身份，也不承诺某人物更强。

## 7. 无障碍、性能与稳定性

正文在三种主背景上的对比度最低约 7.55:1，主文字最低约 13.05:1。大面积图片上有独立深色遮罩/阅读区域，实施后仍需测最终合成色；不能拿纯色测值代替图片上的实际对比度。禁用控件保留可解释原因。

Tab 顺序与视觉顺序一致；弹窗初始焦点、焦点锁定、背景 inert、Esc 草稿守卫和关闭后的焦点返回必须一起做。自定义头像裁切提供键盘等价操作。动态状态使用适度 aria-live，避免每个 token 都打断读屏。减少动态效果时停用装饰动画与平滑滚动。

不要将整张 Figma 截图作为页面背景来冒充实现。布局、正文、卡片、按钮都是真实 DOM/SVG。角色/人物图片按视口懒加载，列表不要提前解码整套高分辨率 PNG；保留母版，构建时生成适配尺寸和现代格式版本，明确尺寸避免布局跳动。背景可懒加载装饰层，核心表单不能依赖图片加载后才能使用。

保留增量渲染、用户上翻时不抢滚动、断线后真实状态、心跳看门狗、草稿保存、静态资源内容哈希与离线回退。换肤不调整这些协议。设计未替代真实浏览器、Android 安装、触摸和软键盘验证。

## 8. 原型边界

已连接主要页面导航、开局、图鉴示例、档案流程和异常分支。Figma 原型是场景导航，不执行真实登录/写盘/裁切/搜索/模型调用；原地操作与动态结果由施工代码实现。详情模板只连接预言家和雾尺示例，避免错误显示其他角色内容。

补充状态画板为了审核展开了全部信息；实际桌面可以用居中 dialog，手机用底部 sheet/全屏编辑。不要把“状态稿”“施工要求”“示例版本”等设计注释直接作为正常产品文案。示例中的人名、日期、version 和统计不硬编码。

未设置 Code Connect：现有原生 JS/HTML 代码尚没有与新组件一一对应、可发布的实现。不能虚构 `.figma.ts` 映射或宣称设计稿已接通生产代码。

## 9. 推荐施工顺序与验收

A. 先建立独立主题层、字体、间距、按钮/输入/模态 primitives，保持现有事件与数据接口不动。提交截图对比 D01/M01、D06/M06、D18/M18，确认质感后再铺全站。

B. 完成档案中心、头像、简介、归档、回收站和导入导出；复测并发更新、跨档案、恢复令牌失效、磁盘故障、409 与长昵称。不得丢掉用户已有档案和自定义头像。

C. 实施开局三步、AI 配置分层、图鉴、设置；将 reading/compact 布局偏好与座位列表/圆桌视图分开。语言目前仅简体中文，不能把它显示成有实际多语言能力的选择器。

D. 实施局内与复盘，逐一走真人行动、全 AI 观战、每类角色技能、投票/弃票/重连、私人笔记冲突和旧标记迁移。

E. 验收矩阵：320/360/390/430 手机宽度，768/960/1200/1440/1920 电脑宽度；正常/大字/减少动画；输入法打开；长中文昵称、emoji、200 字笔记；空/加载/404/409/413/5xx/离线/恢复；同阶段重复点击；应用重启；关闭再打开恢复。

每批交付必须包含真实运行截图、点击录屏或可重复自动化场景、差异说明和失败项。不把“画面有这个按钮”当成功能验收。沿用仓库 `npm run gate` 与 `app:verify -- --release` 等实际脚本，构建命令以当前 package.json 为准；本次设计交付没有执行或声称这些产品门禁通过。
