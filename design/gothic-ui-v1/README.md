# 月夜议会 · AI 狼人杀双端完整界面设计

Figma: https://www.figma.com/design/eOztPb6PdYZRhhx6YAcQKX

日期：2026-09-25。状态：首版设计交付完成；84 张双端页面/状态稿 + 3 张适配示例。尚未替换生产界面。

## 设计约束

西式哥特、月光旧银、煤黑、克制暗金。尖拱只用于品牌及关键视觉，不包围每个表单。中文思源宋体标题、思源黑体正文，英文 Cinzel Decorative。复用既有狼冠、V3/R2 卡框、角色和 24 位 AI 肖像。

账号是本机玩家档案，不是联网账号：不设计密码、验证码或虚假云同步。登录入口对应选择档案并进入；支持自定义头像、编辑、归档、恢复、导入、导出、删除确认。模型密钥是设备级设置，不随档案迁移。对局归属固化，私人标注不能被误认为真实身份。

## 页面范围（桌面 D / 手机 M 对等）

01 选择玩家进入；02 创建/编辑档案；03 自定义头像裁切；04 玩家中心；05 档案管理；06 游戏大厅；07 开局一：板子与规则；08 开局二：参与/座位/AI；09 开局三：确认与费用；10 AI 服务配置；11 AI 座位配置；12 外观与辅助设置；13 设备与数据；14 角色图鉴；15 角色详情；16 AI 人物图鉴；17 AI 人物详情；18 白天发言；19 夜间行动；20 放逐投票；21 私人笔记；22 终局结算；23 对局历史；24 复盘时间线；25 规则书。

另外覆盖：首次空档案、无存档、加载、连接失败/重连、切档恢复确认、409 笔记冲突、旧标记待确认、导入预览/恢复待处理、归档与删除确认、软键盘布局、小屏与大字模式。正常页面 25×2，补充状态 17×2，含可恢复回收站，不把静态稿当成可运行程序。

## 交互约束

手机主按钮高 52，其他操作至少 48，底栏留安全区；桌面主按钮高 52，其他交互至少 48。可见焦点、禁用态、错误文案与非颜色状态标签；正文不压低对比度。手机长页以滚动帧表达，底部行动区不挡住内容。游戏界面不泄漏隐藏身份；候选/自称/已公开严格区分。

## 施工原则

Figma 作为新视觉规格，现有代码作为功能依据；本轮不直接覆盖 web/。新增 token 暂放本目录，明确为提案。生产映射及实现差异记录在交付文档。既有通用库缺少狼人杀专用组件；本轮使用 Nocturne 本地样式，现有团队 Body 样式保持不动。Code Connect 暂不发布：新设计尚无一对一的已发布代码组件。
