## 画布与结构

- 电脑 42 张、手机 42 张，编号 01–42 成对。另有 3 张适配示例。
- 双端顶层重名 0；自动布局中可见原生 UI 节点横向越界 0；Action 按钮小于 48px 的项目 0。
- 原型共 732 条跨画板反应：电脑 448、手机 284；目标存在性错误 0。同页保存/搜索/动态选择不是原型模拟的真实业务。

## 视觉验证

已审阅各主要构图区：封面入口、大厅、个人资料与头像、表单配置、角色与人物图鉴、局内桌面/手机、夜间选择、私人笔记、终局、复盘、冲突合并、确认页、回收站，以及软键盘/小屏/窄桌面。Figma 导出图保存在 previews/，部分为过程中的 before 对比图；文件名含 before 的不作为施工基准。

发现并修复：档案昵称继承宽度导致截断；手机席位行超宽；图片英雄区文字容器过宽；手机设置/资料页导航选中态；头像缩放按钮触区；筛选徽标触区；输入框边界偏暗；键盘编辑区错误焦点 token；复盘导航归属。对照代码补齐简介、回收站，并纠正将可恢复删除误标为永久删除的文案。

对比度计算（sRGB，纯色）：正文/次级文字在 canvas/surface/raised 上最低分别约 13.05:1 / 7.55:1；金色文字最低 6.88:1；浅红错误文字最低 7.92:1。默认输入边界 60% 次级文字混合 surface，约 3.85:1。图片上文字仍需在最终 Web 渲染中实测合成色，不能由此宣称全产品无障碍已认证。
