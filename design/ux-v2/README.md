# 双端施工视觉参照

直接用浏览器打开 `index.html` 即可。请保留仓库目录结构：页面使用 `../brand/v2/` 的新狼头和 `../../web/assets/avatars/` 的现有 AI 头像。无需安装依赖，不调用真实游戏 API、不保存真实数据。

实施约束与任务清单以 `docs/dual-platform-optimization-plan.md` 为准。样张并非产品页面替换文件，不要直接覆盖 `web/index.html`。

- 电脑区域可演示：选择投票目标、独立打开笔记、切换推测倾向、最多三个候选身份、保存和还原草稿。仅 7 号提供完整示例编辑；没有真实投票。
- 档案区域只演示当前名称与选中态切换；不实现档案持久化或数据隔离。
- 手机区域是静态排版参考；实际页签、技能面板、软键盘、安全区和返回行为均需施工实现。
- 窄屏下电脑样张会折行便于查看；正式产品断点与抽屉行为遵循施工方案，不把展示页折行当作最终交互。
- 品牌区提供 SVG、软件 PNG、透明贴图和 ICO；实际生产图标仍未覆盖。

设计意图：古金、午夜蓝和银灰狼首承担哥特气质；正文与按钮保持克制，优先阅读、辨认和可操作性。
