# 打断与终止行为对照表（卡死清扫审计）

> 本表穷举引擎的全部等待点，标注三类打断（终止对局 / 随时自爆 / 随时决斗）在每个等待点的行为与生效时延。
> 相关修复见提交"逻辑 Bug 清扫"：API 硬闸、AbortSignal 贯通、排队状态可见化、消费期目标降级。

## 打断的提交闸门（src/api.js）

| 提交时机 | 自爆 /explode | 决斗 /duel |
|---|---|---|
| 引擎正等**该玩家自己**的操作（pending.seat===玩家） | ❌ 409"请先完成当前操作（发言阶段请用发言框勾选自爆）"——**防卡死硬闸**：此时打断永远不会被消费 | ❌ 409 同左 |
| 白天发言 / 投票 / PK 阶段 | ✅ 入队（发言间隙生效） | ✅ 入队 |
| 夜晚 / 天亮 / 警长竞选阶段 | ❌ 409"只能在白天发动" | ❌ 409（竞选阶段按官方规则不可决斗；狼人可在竞选演讲里用自爆勾选走吞警徽流程） |
| 已有同类请求排队 | ❌ 409"已提交，等待生效" | 同左 |
| 出局 / 对局结束 / 身份不符 | ❌ 409 | ❌ 409 |

## 等待点 × 打断行为矩阵（引擎视角）

| 引擎等待点 | 终止对局 /terminate | 已排队的自爆/决斗 |
|---|---|---|
| **AI 决策中**（agent.decide，最长 timeout×重试） | `abortSignal` 立即中断在途 fetch，不重试不退避；`game.ask` 捕获后因 forceEnded 抛 ForceEnded → runGame 优雅结算。**生效时延 ≈0**（修复前：需等 LLM 自然返回，最长数分钟） | 排队等待；当前发言结束后的第一个间隙消费（≤一次发言时长）。前端常驻提示"已就绪，当前发言结束后生效" |
| **人类 pending——发言**（speech） | pending 被 reject（ForceEnded）→ 立即结算 | API 已拒绝提交；轮到自己发言时用发言框的"自爆"勾选直接发动 |
| **人类 pending——投票/方向/警徽/警选投票等** | 同上 | API 已拒绝提交（此前的"提交成功但永不生效"是白狼王自爆卡死的主因） |
| **计票中**（secretVote，AI 逐个投票，人类票先行挂起） | abort 中断当前 AI 票 → 快速结算 | 排队；计票完成后由 votePhase 消费（本轮投票作废，符合官方"计票前自爆"） |
| **夜晚步骤 sleep**（死角色停顿，≤2s） | 最多延迟一个停顿周期后经下一个 ask 抛出 | 夜晚不可提交；已排队的请求保留到白天间隙 |
| **警长竞选**（报名/演讲/PK） | 同 AI/人类规则（演讲里的自爆勾选走吞警徽流程） | API 拒绝提交（竞选阶段无消费点，入队即卡） |
| **天亮结算 / 开枪链 / 警徽流转**（连锁 ask，多为 _allowDead） | ask 抛 ForceEnded 快速退出 | 不消费；对局通常即将结束 |

## 消费期降级（flow.js）

| 场景 | 行为 |
|---|---|
| 白狼王自爆排队期间目标出局 | 系统公告"原目标已出局，本次自爆不带人，天黑了"，自爆正常生效 |
| 骑士决斗排队期间目标出局 | 系统公告"决斗目标已出局，本次决斗取消"（修复前为静默丢弃） |
| 自爆者本人在排队期间出局/身份变化 | 请求静默作废（合法性在提交时已校验） |

## 前端约定（双端一致）

1. 轮到玩家自己操作（`v.pending` 存在）时**不显示**打断按钮——打断语义是"打断别人/AI 的回合"。
2. 请求排队后，等待文案**常驻**显示"🔮 自爆已就绪：当前发言结束后立即生效（带走 X 号）"，轮询刷新不覆盖（`queuedInterruptText` 优先于 waitingText）。
3. 上帝视角同样可见 `queued` 字段，便于判"没反应"类求助。
