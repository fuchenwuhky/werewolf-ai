## 二、胜负条件（固定，不做开关）

- **好人阵营**：所有狼人死亡 → 好人胜。
- **狼人阵营（10/12 人局）**：**屠边**——所有神职死亡 **或** 所有平民死亡 → 狼人胜。
- 判定顺序：每次死亡结算后先判"狼全灭"（好人胜），再判屠边。同回合同灭时好人优先（官方：好人杀光狼即胜）。
- 白痴算神职；狼王/白狼王算狼人；暗恋者的类别随绑定对象动态计算。
- **暗牌局（`revealOnDeath` 关）细则**：死者不翻牌，天亮公告**只报死亡、不报死因、不报身份**（AI 上下文与双端 UI 同步裁剪；上帝面板仍可见完整死因）。生前公开行使技能（开枪/骑士决斗/白痴免疫/狼人自爆）仍是公开事实——这是暗牌局唯一的合法身份公开途径。

## 三、身份牌（技能以官方原文为准，详见 roles.js / 游戏内角色图鉴）

| 角色 | 阵营/类别 | 技能（官方口径） |
|---|---|---|
| 狼人 | 狼 | 每晚可袭击一人；白天发言阶段可**自爆**立即天黑 |
| 狼王 | 狼 | 死后可开枪带走一人；**被毒杀不可开枪**；被枪带走可开枪；普通自爆不能带人 |
| 白狼王 | 狼 | **仅白天自爆时**可带走一名玩家；被带走者无遗言；非自爆出局不得发动 |
| 预言家 | 神 | 每晚查验一人：好人/狼人 |
| 女巫 | 神 | 解药救当晚被袭者、毒药毒一人；**每晚最多一瓶**；夜间知晓刀口 |
| 猎人 | 神 | **"当且仅当"被狼袭或被放逐**时可翻牌开枪；被毒杀不可开枪；被白狼王带走可开枪 |
| 守卫 | 神 | 每晚守护一人（可自守），被守护者当晚免于狼袭；**不能连续两晚守护同一人**；盾不防毒 |
| 白痴 | 神 | 被放逐时翻牌免疫该次放逐，此后可发言**不可投票**；死于其他原因技能失效 |
| 骑士 | 神 | 白天可翻牌决斗：决斗狼人→其出局并直接天黑；决斗好人→骑士以死谢罪，白天继续 |
| 摄梦人 | 神 | 每晚**必须**摄梦一人（不可自摄）：梦游者当夜**免疫狼刀与毒药**（药照耗）；**连摄两晚同一人→其死亡（救不活）**；摄梦人夜里死→梦游者连带出局（不可守护/救治）；被摄梦死亡的猎人/狼王**不能开枪** |
| 乌鸦 | 神 | 每晚诅咒一人（不可自咒）：被诅咒者次日**放逐投票 +0.5 票**（警长竞选投票不受影响）；每晚重新诅咒覆盖旧的 |
| 隐狼 | 狼 | 狼营暗牌：夜里**不睁眼**、不参与狼聊与刀口、也不知道刀口；**隐狼知道狼队友，狼队不知道隐狼**；**被查验永远是"好人"**；不能自爆 |
| 狼美人 | 狼 | 参与狼刀；每晚魅惑一人（不可自魅/魅狼）：她被**毒/放逐/枪杀/摄梦死**→被魅惑者**殉情出局**（无遗言无技能）；**死于骑士决斗则魅惑失效**；不能自爆 |
| 暗恋者 | 特殊 | 首夜最先行动暗选暗恋对象：胜负阵营与其**终身绑定**（神算神/民算民/狼随狼营，屠边判定跟随）；**查验她永远是"好人"**；绑定不因对象死亡失效 |
| 平民 | 民 | 无能力 |

- 同守同救（守卫守护 + 女巫同夜救同一被袭者）＝ 技能抵消，目标**仍死亡**（"奶穿"），视同被狼袭 → 猎人/狼王可开枪（官方赛事计分明确区分"守到且未同守同救"）。
- 守卫盾对毒药无效（官方）。

## 四、夜晚流程

- 夜晚行动顺序（每晚固定，可配）：**暗恋者（仅首夜）→ 守卫 → 摄梦人 → 狼人 → 狼美人 → 预言家 → 女巫 → 乌鸦**；板子里不存在的步骤自动跳过（含播报，防时长推断）。
- 暗恋者：仅首夜行动，暗选暗恋对象（仅自己可见）。
- 守卫：选守护目标；不可连守（可空守）；同守同救按 §五开关判定。
- 摄梦人：每晚必须摄梦一人（不可自摄、不可空过）；结算规则见 §七点六。
- 狼人：狼队私聊频道（互相可见，**不含隐狼**），依次简短表态 → 各狼投票选刀口（可空刀）→ 多数决，平票在并列中随机 → 最终刀口仅狼队与上帝可见。
- 狼美人：单独睁眼魅惑一人（不可自魅/魅狼）；最新魅惑覆盖旧的。
- 预言家：查验一人（不可验自己），结果仅自己可见；**查验隐狼/暗恋者结果恒为"好人"**。
- 女巫：**始终睁眼知晓刀口**（即使双药已空）。可选：解药救刀口（若未用）/ 毒药毒任意存活者（若未用）/ 空过。两瓶药不可同夜使用。自救受 §五开关限制。刀口若为梦游者，解药视为"已使用但落空"。
- 乌鸦：诅咒一人（不可自咒）；诅咒在**次日白天的放逐投票**生效（+0.5 票），警选投票无效。
- 天亮结算死亡：被袭（未被救/未触发同守同救豁免）+ 中毒者死亡；无人死亡为"平安夜"。平安夜可能是刀口撞上梦游者（被摄梦免疫）。

## 六、警长竞选流程（首夜之后、宣布死讯之前）

1. **上警报名**：按座位顺序依次决定上警/不上警（公开）。
2. **警上演讲**：警上按座位顺序依次发言；发言结束时可**退水**（退出竞选；退水者既无被投票权也无投票权）。
3. **竞选投票**：**只有警下（从未上警）玩家可投票**，可弃票；票型收齐后公开亮票（谁投谁）。
4. **平票**：平票者按与首轮**相反顺序** PK 发言 → 警下重投（只能投平票者）→ **再平票则本局无警徽**；全部弃票（0 票）→ 无警长。
5. **自爆吞警徽**：竞选任何阶段（含 PK）狼人可自爆，按 §五 #2 模式处理；警徽被吞后本局无警长。
6. **警长权利**：白天放逐投票 1.5 票；每天决定发言方向（顺/逆时针）；**压轴最后发言**；死亡时（含夜晚）在死讯公布时**移交警徽**给任意存活者或**撕毁**。
7. **AI 警徽策略**（工程功能，`src/ai/strategies.js` BADGE_STRATEGIES）：每个身份都有专属的**持徽期打法**（发言归票/方向选择/票权使用，随发言、方向、投票任务动态注入）与**死后流转策略**（随警徽移交任务注入）——好人系优先"徽给金水/可信好人、尽量不撕"，狼系优先"徽递队友续冒充链、身份崩则撕徽拒缴 1.5 票"；暗恋者按推断的绑定阵营行事。

## 七、白天流程

1. **死讯**：公布昨夜死者（或平安夜）；首夜死者依次留遗言（之后夜晚死者无遗言）。
2. **发言顺序**：有警长 → 警长选方向（以首个死者下家为起点；平安夜以警长下家为起点），其余人依次发言，**警长压轴**；无警长 → 死者下家顺时针（平安夜随机起点）。
3. **自爆**：轮到自己发言时可自爆（狼阵营）→ 翻牌公开；白狼王可带走一人（被带走者无遗言）；若首夜死讯尚未公布，先公布死讯与遗言再天黑；警上阶段自爆按吞警徽处理。
4. **放逐投票**：存活者按座位顺序**秘密投票**（每票仅投票者本人与上帝可见，互相不可见、无顺序信息），可弃票，警长 1.5 票；收齐后公开亮票。
5. **平票 PK**：平票者按当日发言顺序的**逆序** PK 发言 → 其余存活者（不含 PK 者）重投、只能投平票者 → 再平票则当日无人出局。
6. **放逐结算**：白痴触发免疫翻牌（存活但永久失去投票权）；否则放逐出局、留遗言；警长出局先移交警徽；随后猎人/狼王翻牌开枪（枪下死者无遗言，可连锁开枪）。
7. 每批死亡结算后判定胜负，未分胜负进入下一夜。

## 七点四、白狼王骑士场（12人）

- 板子：白狼王×1 + 狼人×3 + 预言家/女巫/骑士/白痴×各1 + 平民×4。
- **骑士**：除警长竞选阶段外，白天任意玩家的发言阶段可翻牌发起决斗。决斗狼人 → 该狼立即出局并直接天黑（无遗言）；决斗好人 → 骑士出局以死谢罪（无遗言），白天继续发言与投票。
- **白狼王**：可自爆带走一人（同随时自爆机制）。AI 白狼王与骑士在**每次玩家发言结束后按随机顺序**被询问是否发动技能；人类玩家则有「🔮 随时自爆」「⚔️ 随时决斗」常驻按钮（发言/投票/PK 阶段可用）。

## 七点五、狼人自爆（官方：白天随时可自爆）

- 狼人（含狼王/白狼王）可在**白天发言/投票阶段的任意时刻**自爆——不必等轮到自己发言。实现上由人类玩家端"🔮 随时自爆"按钮发起，引擎在**最近的发言间隙**（当前发言者说完后立即）生效：公开狼人身份、当夜即刻降临，未完成的发言与投票全部作废。
- 白狼王自爆可带走一名存活玩家；普通狼人/狼王自爆不带人。
- AI 狼的自爆决策点：天亮后（每 early morning 一次评估）+ 自己发言/警上演讲轮内；由规则 `allowSelfExplode` 总开关控制。
- 警长竞选期间的自爆走"吞警徽"流程（见自爆吞警徽规则）；随时自爆仅在白天发言/投票阶段开放。

## 七点六、新角色细则（摄梦人 / 狼美人 / 乌鸦 / 隐狼 / 暗恋者）

**摄梦人**（官方规则页）：
- 每晚必须选择一名其他玩家摄梦（不能空过、不能自摄），该玩家成为当夜"梦游者"。
- 梦游者当夜免疫狼刀与女巫毒药——相关技能"视为已使用但落空"（女巫的解药/毒药照样消耗）。
- 同一人被**连续两晚**摄梦则死亡，**女巫救不活**；死因不计入猎人/狼王的开枪触发（同毒杀口径）。
- 摄梦人自己夜里死亡时，当晚梦游者**连带出局**（不可守护、不可救治）。
- 引擎实现：结算顺序＝狼刀/毒/同守同救 → 梦游者免疫移除 → 连摄死亡 → 摄梦人死则连带；同座位多重死因去重按 毒 > 连摄死 > 其余 优先。

**狼美人**（官方攻略 + 百度百科）：
- 参与狼队讨论与刀口；另有单独夜晚步骤魅惑一人（不能是自己或狼队成员），最新魅惑覆盖旧的。
- 触发殉情的死因：毒杀、放逐、枪杀、摄梦系死亡（连摄死/连带死）；**骑士决斗致死不触发**（魅惑作废）。
- 被魅惑者殉情出局：**无遗言、不能发动技能**（猎人殉情不开枪）；若殉情者是警长仍按警徽流程流转（属系统结算而非技能）。
- 狼美人不能自爆（角色配置 `selfExplode: false`）。

**乌鸦**（官方说明，TapTap 口径 +0.5 票）：
- 每晚诅咒一人（不可自咒）；被诅咒者在**次日放逐投票**（含 PK 投票）中被额外计入 **+0.5 票**。
- 警长竞选投票不受诅咒影响；每晚重新诅咒覆盖之前的目标。
- 引擎实现：`game.activeCurse` 在夜晚结算时写入、新的一夜开始时清空；亮票事件带 `curseBonus` 标注，票数统计显示 0.5 票。全员弃票但被诅咒者有 0.5 票时按规则出局（半票即最高票）。

**隐狼**（乌鸦隐狼板）：
- 夜晚不睁眼：不参与狼聊、不投刀、也看不到刀口结果（`nightStep: null`，不进狼队频道可见性）。
- 互认规则：**隐狼知道狼队友，狼队不知道隐狼**（发牌 `teammates` 事件按此裁剪，AI 私密账本同步裁剪）。
- **被预言家查验永远是"好人"**；可被骑士决斗（决斗按真实队伍判定）、可被狼队之外的伤害正常带走。
- 胜负：算狼营（屠边判定计入），好人需放逐他才能获胜；不能自爆。

**暗恋者**（上线公告）：
- 首夜**最先行动**，暗选一名暗恋对象（仅自己可见；对方不知情）。
- 胜负阵营与对象**终身绑定**：对象是神职算神、平民算民、狼营算狼（屠边判定用 `game.categoryOf` 动态类别）；对象死亡不影响绑定。
- **预言家查验暗恋者永远是"好人"**（即使绑狼）——绑狼时她是"验不穿的第四狼"。
- 骑士决斗按身份牌阵营判定：暗恋者非狼牌，决斗她=决斗好人（骑士谢罪）。

## 八、猎人 / 狼王 / 白狼王开枪细则

- 猎人可开枪死因：被狼袭（含奶穿）、被放逐、被枪带走；**被毒杀不可**。
- 狼王可开枪死因：同猎人（官方：被枪带走可开枪，被毒不可；本项目无丘比特故无殉情）。
- 白狼王：仅自爆时带人，非开枪技能。
- 开枪者可在**任意存活者**中选目标或放弃开枪；连锁：枪带走狼王/猎人 → 其可继续开枪。

## 九、投票保密性（本项目硬性规定）

- 放逐投票、警长竞选投票：按座位顺序依次收集（便于人类操作），但**每张票只对投票者本人与上帝可见**，其他玩家（含 AI）的上下文中完全不存在。
- 收齐后生成公开"亮票"事件（含谁投谁与加权票型），此时才进入所有人上下文。

## 十、记忆隔离与缓存（工程规定，非游戏规则）

- 全局事件日志，每条事件带可见性标签（`all` / 座位数组 / 仅 god）；任何一侧（人类前端、AI 上下文）都只能通过唯一过滤函数取事件。
- **分层记忆架构（v2，替代旧 append-only 原型）**：每次决策一次性组装单条 user 消息，上下文体积恒定（默认预算 `contextBudget`=12000 tokens，估算值），不再随天数线性膨胀：
  - **L1 纪要层**：第 1..N-2 天的每日反思摘要（Generative-Agents 式 reflection）。每天结束时由该 AI 用一次 LLM 调用生成 ≤700 字结构化纪要（身份判断表+关键发言+硬事实+我的状态），全天复用、当日内逐字节稳定；生成失败自动降级为**确定性事实骨架**。
  - **L2 实录层**：昨天 + 今天的全部可见事件逐字实录（窗口滚动），保证近期逻辑链完整。
  - **局面快照**：代码确定性生成，零幻觉——当前时刻（第X天·阶段）、座位与存活/翻牌/警长状态、"你确知（私密账本：查验/刀口/用药/守护/队友）"、"你不知道（禁止臆测）"两组清单、公开硬事实时间线、"自上次行动的新事件"清单。
  - **缓存友好排序**：稳定区（system → L1 → 昨日实录）在前、易变区（快照+任务）最后；同一天内前缀逐字节稳定（有单测守卫）。
  - **预算裁剪顺序**：昨日实录降级 → 实录保尾截断 → **记忆按 recency×importance×relevance 检索**（P2-5 起取代了旧的"丢最旧纪要"；装得下时不做任何检索，逐字与旧行为一致）；快照与任务永不裁剪。
- **时间与信息常识（防幻觉铁律，system 常驻）**：第1夜狼人只知道队友、不知道任何人身份（禁止"首夜刀预言家"式无信息剧本）；只基于时间线上真实出现过的事件推理，日志里没有的事就是没发生；翻牌即确定事实；私密信息以快照"你确知"为准。
- 每次调用记录 `prompt_tokens / cached_tokens / completion_tokens / 延迟 / 重试`，上帝面板展示缓存命中率与最近一次组装的完整上下文（`contextTokens` + 各分区）。
- **任务分层思考强度**：发言/遗言/PK/警上演讲用 `reasoningEffort`（默认 high），夜晚行动/投票/警竞/狼队表态等结构化决策用 `fastEffort`（默认 low）+ `fastMaxTokens`（默认 8000）压低最坏延迟；**每档的实际 thinking 有 5 级**（`minimal/low/normal/high/critical`，见 `src/ai/effort.js`），按"这一轮新增了多少决定性事件 / 是否关键节点 / 是否终局"自动升降（`effortPolicy: info`，默认），最终仍只会落到 low 或 high 两种 effort；旧的按任务名一刀切（`flat`）保留用于 A/B 与回滚。（用户可选的"节奏档位"快速局/标准局/深度局就是这一组参数的预设。）
- **投票时间利用率**：投票阶段开始时人类的投票界面立即就绪（无限时），AI 按座位顺序逐个思考——人与 AI 同时进行，互不阻塞；**默认单 Key 时 AI 之间不并行**（防限流）；配置多 Key 后由 `src/ai/scheduler.js` 的**通道池**接管（每 Key 一条通道、通道内仍严格串行，槽位固定绑定 Key 以保住服务商侧 prompt 缓存），此时**互不依赖的夜晚步骤与投票**才会扇出（夜晚唯一的依赖是"女巫等狼刀"），而提交顺序与归集顺序仍是座位顺序，票型、亮票顺序与步骤播报顺序都不受影响。收集期间服务端会播报 `vote_progress`（只给"已思考 N/M"计数，**不含任何目标或座位**，且不进 AI 上下文），前端据此显示进度，避免长达数分钟的无信息等待。（实测多 Key 的收益上限约 −19%，不是"减半"——见 `docs/fluency-plan.md` §1.4/§8.5。）
- **多 Key（并发通道）**：设置页的「更多 API Key」可以填多把 Key（一行一个或用逗号分隔），**每多一把就多一条并发通道**（也可以在配置里用 `llmChannels` 强制指定通道数）。通道池的规则是"每 Key 一条通道、通道内严格串行"，且槽位固定绑定 Key —— 同一条通道的连续请求打同一把 Key，服务商侧的 prompt 缓存才不会因为换 Key 而全部落空。某把 Key 触发配额/鉴权类致命错误时会被**临时摘除 5 分钟**，其余通道继续干活（一条通道坏了不拖垮整局）。**单 Key 时行为与从前逐字节相同**（不扇出、不开并行）。注意：通道数**不是线性提速**，实测 4 通道约 −19%，因为发言必须按顺序听。
- **超时与降档**：单次调用有分任务软超时（发言/遗言类 90s，夜晚行动/投票等结构化微决策 30s；旧的 6 分钟 `timeoutMs` 只作硬上限兜底），超时先**降档重试**（思考强度压到最低、预算收紧）而不是原样再等一次；单次决策还有 180s 的总时长闸，超过就直接降级出一手合法但平凡的棋。**降档与降级一律留痕**（god 可见 `llm_error`，最终降级带 `degraded`），所以"AI 这轮答得特别短/特别保守"在复盘里查得到原因。
- **公开宣称账本（防幻觉）**：AI（与人类玩家）发言里的**身份自称**与**查验/用药宣称**会被引擎确定性地扫描出来，落成 `claim` 事件并在快照里单列「**公开宣称（未经证实）**」区，与「公开硬事实时间线」**物理隔开**。核心区分是：**"某人说了什么"是事实，"他说的内容"不是**——所以每条宣称都带 `verifiedBy: null`（引擎永不替它背书），事件字段集合封闭、**绝不携带说话者的真实身份**。下一位 AI 读到的是「3号 **声称** 5号 是狼（查杀）（未经证实）」，而不是「5号是狼」；否定句与假设句（"我不是预言家""如果我是预言家"）不计入。该区有界：每个座位只保留最近一次自认身份 + 最近若干条查验/用药，超出部分写明省略条数。局终点评会做**一致性核查**：真预言家验错、好人假跳神职会被点名；**狼人的宣称不算矛盾**（狼必须能撒谎），但会被列出来供人复盘。
- **玩家身份标记**：前端功能，玩家可给未暴露的存活玩家标注"可疑身份"（仅自己可见的笔记，存于浏览器 localStorage，AI 上下文不包含）；标记选项自动排除已不可能的身份（该身份全部已翻牌/玩家自己持有唯一该身份等），允许多名玩家标同一身份。

## 十一、AI 性格系统（本项目功能）

- 每名 AI 在对局创建时获得一种**性格**（内置 14 种：激进鹰派/稳健防御/侦探推理派/搅局鬼才/老好人/毒舌贵妇/戏精本精/神秘主义者/暴脾气/学究/和事佬/阴沉寡言/新手小白/十年老油条），影响说话风格、语气与策略倾向，**不改变阵营目标**。
- 分配规则：设置页"高级：AI 人格设置"中可按座位自定义（下拉选择内置性格或输入自由文本，自定义优先）；**留空的 AI 每局随机分配**，同一局池内性格不重复。手机端全部随机。
- 性格注入 system prompt（整局不变，前缀缓存友好）；**性格对玩家完全不可见**（不下发前端、不显示标签），仅影响 AI 的表达方式。
- **阵营立场铁律**（修复"狼人遗言帮好人"问题）：狼人的一切发言必须服务狼阵营——不给出指向队友的可验证真信息、不替好人复盘正确结论、永不卖队。真假参半是明确允许的常规战术。
- **狼人临终战术菜单**（遗言指令按身份与翻牌状态 `revealed` 定制）：翻牌后五套打法——认狼护队（认狼后至多咬 1 个好人）、真假参半（死无对证的"真"建信誉+关键假信息）、反向咬人、好人榜（名单里好人与队友数量参半、相差≤1，队友放中段，只报名单不解释）、不配合（谜语人/嘲讽）；红线：不翻供不求饶，名单配比失衡等于卖队友。
- **职业策略模版库**（`src/ai/strategies.js`）：9 职业 × 2~5 个官方主流打法模版（狼队：悍跳/冲锋/深水/倒钩/好人榜；预言家：上警警徽流/强验/后置起跳；女巫：首夜救人/谨慎毒药/起跳带队；守卫：守神/自守循环；猎人/白狼王/白痴各专署；平民：逻辑站边/挡刀/诈跳预言家（真预言家不在场时可假跳骗狼刀）/表水扛推），每条 ≤120 字，全部常驻注入 system「推荐打法」段供 AI 参考（可灵活应变，不必照搬，走前缀缓存）。
- **提示词体积守卫**：单测限制狼人/预言家 system 总长上限（2200/2000 字符），防止提示词再度膨胀拖慢思考。
- **基础知识注入**（system 共享前缀，全场一致）：①本局职业配置（板子及数量）；②职业一览（在板职业的技能简介，来自 ROLES.short）；③流程常识——狼人夜里只决定刀口、当晚无任何结果消息（可能被守护/被救），是否得手等天亮公告；不要声称不可能知道的夜间信息；女巫首夜可救可不救、解药毒药各限一次；猎人被毒无法开枪。
- **遗言反结构化铁律**：狼人遗言绝不允许出现"好人榜/排序/分组"等可解码结构——好人用已知查验核对一个名字即可解出整张名单（前排=被保护队友）。点名上限 1 个具体好人，绝不点名队友（提及即信息）。
- **悍跳体系**：system 提示词向狼人开放悍跳战术（警上悍跳预言家：假查验+警徽流+心路历程；全队仅一人跳同一身份，首夜狼队频道协同），并明确"反幻觉禁令不限制战术性伪装"。sheriff_run/sheriff_speech/wolf_chat 均有对应角色感知引导。
